# เซียมซีตำหรับเจ้าเรือน

เว็บเสี่ยงเซียมซีตามธาตุเจ้าเรือน (ดิน น้ำ ลม ไฟ) ธาตุละ 7 ใบ รวม 28 ใบ
เลือกเดือนเกิด → รู้ธาตุ → เขย่ากระบอก → เปิดอ่านคำทำนาย เมนูแนะนำ และเครื่องหอมประจำใบ

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | ตัวเว็บทั้งหมด (หน้าตา การทำงาน และข้อมูลคำทำนาย) |
| `bg-full.jpg` | พื้นหลังรวมสี่ธาตุ ใช้ในหน้าแรกและหน้าเลือกเดือน |
| `bg-earth-full.jpg` | พื้นหลังธาตุดิน |
| `.nojekyll` | ไฟล์ว่าง บอก GitHub Pages ให้แสดงไฟล์ตามที่เป็น |

## วิธีขึ้นเว็บด้วย GitHub Pages

1. เข้า [github.com](https://github.com) แล้วกด **New repository** ตั้งชื่อ เช่น `siamsi-tamrap` เลือก **Public** แล้วกด **Create repository**
2. ในหน้า repository กด **uploading an existing file** (หรือ **Add file → Upload files**)
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง (`index.html`, `bg-full.jpg`, `bg-earth-full.jpg`, `.nojekyll`, `README.md`) แล้วกด **Commit changes**
   - ถ้าลากไฟล์ `.nojekyll` ไม่ได้เพราะเครื่องซ่อนไฟล์ที่ขึ้นต้นด้วยจุด ข้ามไปได้ เว็บยังทำงานได้ปกติ
4. ไปที่ **Settings → Pages**
5. ช่อง **Source** เลือก **Deploy from a branch** ช่อง **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที แล้วรีเฟรชหน้า Settings → Pages จะเห็นลิงก์เว็บ เช่น
   `https://ชื่อผู้ใช้.github.io/siamsi-tamrap/`

## แก้ไขข้อมูลภายหลัง

เปิด `index.html` บน GitHub แล้วกดรูปดินสอ (Edit) ข้อมูลอยู่ส่วนบนของโค้ด หาได้จากคำเหล่านี้

- `const ELEMENTS` — ข้อมูลธาตุ (เดือนเกิด สี รส บุคลิก สิ่งที่ควรระวัง)
- `const FORTUNES` — คำทำนาย 28 ใบ (กลอน ความหมาย ข้อควรระวัง เมนูแนะนำ)
- `const SCENTS` — เครื่องหอมประจำใบ ชนิดที่ 1–7 ตรงกับใบที่ 1–7
- `const BG` — พื้นหลังประจำธาตุ

### เพิ่มพื้นหลังของธาตุอื่น

1. อัปโหลดภาพเข้า repository เช่น `bg-water-full.jpg`
2. แก้ใน `const BG` เพิ่มบรรทัด เช่น
   `water: { full:"bg-water-full.jpg", color:"#eef4f8" },`
   (`color` คือสีพื้นที่เห็นระหว่างรอภาพโหลด ใช้สีอ่อนที่ใกล้กับภาพ)
3. ชื่อธาตุที่ใช้ได้: `fire` (ไฟ), `wind` (ลม), `water` (น้ำ), `earth` (ดิน)

## หมายเหตุ

- ฟอนต์โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ต ถ้าออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน
- การสุ่มใช้ `crypto.getRandomValues` ไม้ทั้ง 7 มีโอกาสเท่ากัน ไม่ขึ้นกับแรงหรือเวลาเขย่า
- เพื่อความรู้และความบันเทิงตามความเชื่อแพทย์แผนไทย ไม่ใช่การวินิจฉัยโรค หากมีอาการผิดปกติควรปรึกษาแพทย์
